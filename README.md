## 📌 Project Overview

This project analyzes **3,900 customer purchases** across **18 columns** to understand shopping behavior, customer segments, product preferences, discounts, shipping choices, subscription behavior, and revenue patterns.

The complete workflow follows:

**Raw Data → Python Cleaning → PostgreSQL → SQL Analysis → Power BI Dashboard → Business Insights**

---

## 🎯 Business Problem

A retail company wants to better understand customer shopping behavior to improve sales, customer engagement, satisfaction, and long-term loyalty.

The analysis focuses on questions such as:

- Which customer segments generate the most revenue?
- How do discounts relate to customer spending?
- Which products receive the highest ratings?
- How does shipping type relate to purchase value?
- How do subscribers compare with non-subscribers?
- Which products are most dependent on discounts?
- How can customers be segmented based on purchase history?
- Which age groups contribute the most revenue?
